# 2026-10-04 审查问题处理

本次核对当前源码并修复；主机测试不等于 iOS 模拟器运行、签名发布或 Android 真机帧率验证。

| 项目 | 处理 |
| --- | --- |
| 1. 预览超时预算 | 渲染脚本使用统一 540 秒截止时间，所有外部命令受剩余预算约束；清理最多 40 秒，外层步骤 12 分钟、任务 45 分钟。启动超时直接失败。 |
| 2. 预览触发范围 | 增加 `lib/**`、`ios/**`、`assets/**`、依赖文件及预览测试的变化。 |
| 3. 预览静默失败 | 每次启动使用新的 nonce；Dart 页面完成渲染后，经原生通道确认页面、外观与 nonce。收到对应确认后才截图，拒绝黑色或空白内容。常规构建中的旧诊断截图移除，统一使用经过校验的预览工作流。 |
| 4. TestFlight 机密范围 | 先完成无签名归档，之后分别为证书导入与上传步骤提供必要机密；导出归档不运行 Flutter/CocoaPods 构建脚本。显式掩码 P12 密码，不发布已签名 IPA artifact，始终清理临时材料。 |
| 5. 可访问性 | 辅助导航开启时保持导航可见、可聚焦、可朗读和可点击；普通模式继续遵守上滑隐藏、回到顶部显示。 |
| 6. 导航几何 | 默认高度 72 dp、圆角 28 dp，与规格一致；大字体额外增高。边距、阈值、动画、模糊和断点集中为命名常量；底部留白按实际导航高度计算。 |
| 7. 性能 | 正常每秒速率刷新仅重建总览连接区域；硬件、标题、状态区玻璃和导航不随每秒更新重建。错误、恢复、完整刷新仍更新页面。保留完整玻璃强度。原有 `RepaintBoundary` 已位于胶囊玻璃外侧，并非只包内层；本次增加实时连接区域边界。 |
| 8. favicon 父域回退 | 手机和 LuCI 都优先精确域名，再尝试同一已识别后缀边界内的最近父域；未知后缀只用精确查询。包内图标优先，已列出共享托管边界不跨租户。此实现是保守后缀集合，不声称包含完整公共后缀数据库。 |
| 9. 缓存文档 | 计划改为 4096 条、16 MiB；明确这与手机旧版 256 行索引截断不同。 |
| 10. 注入脚本 | 检查每个锚点唯一且存在，写入前验证所有内容；注入带标记且幂等，局部注入、旧注入内容或锚点漂移都明确失败。 |
| 11. Android 死分支 | 删除不再调用的 `accentColor` 分支，保留 `getAppearance` 与外观事件。 |
| 12. 计划状态 | 同步滚动顶部的已推送状态和辅助导航修订，勾选不等于后续 CI 一定通过。 |
| 13. 工具测试 | 增加预览准备、启动超时、就绪匹配、截图校验、清理与签名工作流机密范围测试；Android 和 iOS 常规构建都执行工具测试。原发布工作流也已运行签名测试，并非只在 Android 中运行。 |
